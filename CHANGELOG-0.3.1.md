# 🛠️ Version 0.3.1 (Multiplayer Bug Fix)

## 🐞 Bug Fixes

- **Партии на 3–6 игроков:** исправлены определение козыря при полной раздаче колоды, переход атаки после взятия и порядок добора. Защищающийся добирает последним.
- **Ходы и доброс:** текущий ход указывает на защищающегося, пока на столе есть непокрытые карты. Доброс после «Взять» работает. Завершать раунд может ведущий атакующий, а не любой участник. Перевод ограничен шестью картами; отмена атаки не разрушает уже сделанные защиты и переводы.
- **Синхронизация:** один последовательный канал отправки на каждое соединение сохраняет порядок состояний. Клиент получает свой идентификатор до начала партии; одинаковые никнеймы не смешивают руки.
- **Подключения:** устранены гонки старых соединений при повторном создании комнаты, зависание при закрытии читающего сокета и потеря уведомления об отключении. Начало партии проверяет состав комнаты и завершение подключения участников.
- **Локальная сеть без интернета:** IP определяется по сетевым интерфейсам, без подключения к внешнему DNS-серверу.
- **Стол:** все 2–6 мест видны одновременно, с именами, количеством карт, ролями и выделением текущего игрока. Исправлены подсказки при взятии и координаты целей для перетаскивания. Большой стол можно прокрутить.

## 🛠️ Changes

- Содержимое Roadmap временно заменено сообщением «Временно меняется».
- Подзаголовок главного меню сохраняет название глобального обновления 0.3 во всех языках.
- Версия Android: `0.3.1-standalone`, `versionCode = 4`.
- Сохранён идентификатор `com.aistudio.durak.kgworp.v03`. Для обновления опубликованной 0.3 используется тот же существующий ключ подписи.
- Для подписи release поддерживается переменная `KEY_ALIAS` (по умолчанию `upload`). Приватные ключи и результаты сборки не хранятся в Git.

## Проверка

- Unit-тесты движков и протоколов, в том числе 100 полных партий на 2–6 игроков с колодами 36/52 в классическом и переводном режимах.
- TCP-тесты порядка и приватности сообщений для пяти клиентов.
- Android-тесты реальных TCP-комнат на 3, 4, 5 и 6 участников, отключений и повторного создания комнаты.
- Compose-тесты видимости всех шести мест на узком экране, заглушки Roadmap и полного стола через настоящий ViewModel и TCP-клиентов.
- Сборка APK, Android Lint, сравнение сертификатов и проверка обновления прежней 0.3 на эмуляторе.

Проверка через несколько физических телефонов и разные Wi-Fi-роутеры остаётся отдельным этапом. Сетевой тест использует несколько настоящих TCP-клиентов на одном Android-эмуляторе.
