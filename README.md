## Описание
**Dyrachok Offline** — это мобильная и ПК-игра по мотивам классического карточного «Дурака». Проект сочетает в себе каноничные правила, плавный визуальный стиль, атмосферное музыкальное сопровождение и закладывает мощный фундамент для будущих кроссплатформенных сетевых баталий.

---

## 💻 Платформы
* **Android** (Основная мобильная версия)
* **Windows** (Официальный порт, работающий нативно без эмуляторов)

---

## ✨ Ключевые особенности
* **Полное аудиосопровождение:** Каждое действие за столом имеет свой сочный звук, а в эндгейме включается адаптивная музыка (Late Game Theme).
* **Архив матчей (Match Archives):** Все логи прошедших игр бережно сохраняются, освобождая игровой интерфейс от лишнего визуального мусора.
* **Кроссплатформенность:** Сетевой код игры изначально проектируется так, чтобы игроки с Windows и Android могли без проблем играть друг с другом.

## Description
**Dyrachok Offline** is a mobile and PC card game based on the classic Russian "Durak". The project combines canonical rules, smooth visual aesthetics, and atmospheric musical accompaniment while building a solid foundation for future cross-platform network battles.

---

## 💻 Supported Platforms
* **Android** (Main mobile version)
* **Windows** (Official native port, runs directly without emulators)

---

## ✨ Key Features
* **Immersive Audio:** Every action on the table has its own sound effect, featuring an adaptive music system (Late Game Theme) that kicks in when the deck is empty.
* **Match Archives:** Detailed combat logs are safely stored in history, keeping the main gameplay arena clean and minimal.
* **Cross-Platform Ready:** The multiplayer core is designed from the ground up to allow seamless connectivity between Windows and Android players.

---

  * WiFi support for up to 6 players in a single match.
